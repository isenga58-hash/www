Deskripsi:
Aplikasi web sederhana untuk mengambil data temperatur per jam
dari Open-Meteo API dan menampilkannya dalam tabel.

API:
https://api.open-meteo.com/v1/forecast?latitude=-6.2&longitude=106.8&hourly=temperature_2m

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder proyek.
3. Buka index.html menggunakan browser.
4. Pastikan komputer terhubung internet.
5. Data cuaca akan dimuat otomatis.

Field yang ditampilkan:
- time
- temperature_2m (°C)

Teknologi:
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API
